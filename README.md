# Ритм дня

Локальный трекер задач и привычек на русском языке. Первая версия сделана как PWA: открывается в браузере, работает офлайн и может быть установлена как десктопное приложение через меню браузера.

## Возможности

- задачи на выбранный день;
- категории из отдельного справочника, дедлайн, напоминания и приоритеты;
- расширенные повторы: дни, будни, выходные, неделя, месяц, год;
- привычки с галочкой или числовой дневной целью;
- счетчик серии привычек;
- недельный обзор и календарный heatmap;
- drag-and-drop сортировка задач внутри дня;
- архив завершенных задач;
- экспорт и импорт JSON;
- локальное хранение через `localStorage`;
- фоновые напоминания в Electron, пока приложение работает в трее.

## Запуск

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:5173/`.

## Десктопная версия

Установить зависимости:

```powershell
npm install
```

Запустить отдельное окно:

```powershell
npm run desktop
```

Собрать Windows-версию:

```powershell
npm run build:win
```

Готовые файлы появятся в папке `dist`.
