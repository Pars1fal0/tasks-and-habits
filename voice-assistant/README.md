# Codex Voice Assistant

Лёгкий локальный помощник для голосовой активации Codex на Windows.

## Установка

Открой PowerShell в этой папке и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Установщик создаёт отдельное Python-окружение, загружает русскую модель Vosk размером 45 МБ и добавляет помощник в автозапуск Windows.

## Использование

1. Открой Codex.
2. Скажи `Кодекс работай`, `Кодекс работать` или `Кодекс слушай`.
3. После двойного высокого сигнала продиктуй задачу.
4. Скажи `Отправь` или `Отправить`.
5. Скажи `Отмена`, чтобы сбросить команду без отправки.

Фразы меняются в `config.json`. После изменения перезапусти помощник.

Автоотправка после паузы выключена по умолчанию, чтобы ошибочно распознанный текст не отправлялся без подтверждения. При необходимости включи `"auto_send_enabled": true` и настрой задержку `auto_send_seconds`.

Помощник выбирает самое большое видимое окно Codex и разворачивает его, если оно слишком маленькое. Если после изменения интерфейса текст попадает не в поле ввода, поправь `composer_bottom_offset` в `config.json`: большее число поднимает точку ввода выше.

## Управление

```powershell
.\start.ps1
.\stop.ps1
```

При скрытом запуске ошибки записываются в `assistant.log`. Микрофон и распознавание работают локально; аудио Vosk никуда не отправляет. В Codex передаётся только готовый распознанный текст.

В режиме ожидания используется ограниченный словарь ключевых фраз. Маленькая русская модель занимает около 240 МБ оперативной памяти и почти не использует процессор на современном ПК.

Проверить Win32-ввод без отправки сообщения в Codex можно командой `.\.venv\Scripts\python.exe .\smoke_test.py`.
